# Caser.one — Полная копия проекта (1:1 Клон)

Точная копия сайта игрового проекта **caser.one** (CS2 кейсы, апгрейд предметов, еженедельные награды и розыгрыши), выгруженная и развернутая с помощью автоматизированного инструмента парсинга и сборщика ассетов.

---

## 📁 Структура проекта

```
caser-site/
├── index.html                 # Главная страница (редирект/русская локаль)
├── ru/                        # Полная русскоязычная версия сайта
│   ├── index.html             # Главная страница: верстак Апгрейдов и спиннер
│   ├── cases/index.html       # Каталог всех 151 кейсов CS2 с артами и ценами
│   ├── inventory/index.html   # Личный инвентарь игрока
│   ├── rewards/index.html     # Еженедельный набор, ТОП-дроп, розыгрыши
│   ├── tos/index.html         # Пользовательское соглашение
│   ├── privacy/index.html     # Политика конфиденциальности
│   ├── cookie/index.html      # Политика cookie
│   ├── aml/index.html         # AML/KYC политика
│   └── contacts/index.html    # Контакты и реквизиты
├── en/                        # Англоязычная версия (все страницы)
├── _next/                     # Скомпилированные чанки Next.js и Turbopack
│   └── static/
│       ├── chunks/            # Стили (.css) и клиентские скрипты (.js)
│       └── media/             # Шрифты (.woff2)
├── cdn/                       # Все медиа-ресурсы и графические ассеты
│   ├── cases/                 # Арты и обложки всех 151 кейсов
│   └── fa/
│       ├── icons/             # SVG иконки, оружие, флаги, платежные системы
│       └── images/            # Фоны, текстуры верстака, логотипы, барабан
├── cases.json                 # Извлеченная база данных кейсов (151 шт.)
├── cases_cache/               # Кэшированные предметы кейсов (4393 шт.)
├── store.js                    # Слой хранения: SQLite (локально) или Turso (облако)
├── server.js                  # Сервер Node.js (Express + WebSocket + API)
├── render.yaml                 # Blueprint для деплоя на Render
├── .env.example                # Переменные окружения (DATABASE_URL, ...)
└── package.json               # Зависимости проекта (express, ws, @libsql/client)
```

Драйвер БД: [`@libsql/client`](https://github.com/tursodatabase/libsql-client-js) — работает
одинаково с локальным файлом (`file:`) и с Turso (`libsql://`), поэтому один и тот же
код работает и локально, и в продакшене.

## 🚀 Запуск проекта

### 1. Установка зависимостей
```bash
cd caser-site
npm install
```

### 2. Запуск сервера
```bash
node server.js
```
Сервер будет доступен по адресу: **`http://localhost:3000`** (или `http://0.0.0.0:3000`).

## 💾 Хранение данных

Баланс, инвентарь, история транзакций и лог открытий хранятся в **SQLite**.
Драйвер — [`@libsql/client`](https://github.com/tursodatabase/libsql-client-js), который
умеет два режима и поэтому один и тот же код работает локально и в облаке:

| Режим | Конфигурация | Когда данные сохраняются |
|---|---|---|
| **Локальный файл** | `DATABASE_URL` не задан → `DATA_DIR/caser.db` | Пока жив инстанс (Free — обнуляется при спиддауне/редеплое) |
| **Turso (облако)** | `DATABASE_URL=libsql://…` + `DATABASE_AUTH_TOKEN` | Всегда, независимо от перезапусков и деплоев |

- **Аккаунт выдаётся на первый запрос** и привязывается к cookie `caser_user_id`,
  поэтому у каждого браузера **свой** баланс и **свой** инвентарь.
- Если база недоступна — сервер автоматически откатывается в режим «в памяти»
  и продолжает работать (данные живут до рестарта).
- Ледгер: каждое движение баланса пишется в `transactions`
  (`GET /api/users/balance/history`).

### Настройка Turso (бесплатно)

**Самый простой путь — через веб-панель**, без CLI:

1. Открой <https://turso.tech> и зарегистрируйся (GitHub-аккаунт подойдёт).
2. В консоли нажми **Create database**, выбери регион (например `fra`).
3. Скопируй **URL** — он выглядит как `libsql://<имя>.turso.io`.
4. В меню базы → **Tokens** → **Create token** → скопируй токен.

Если хочешь пользоваться терминалом, CLI ставится не через npm:

```bash
# Linux / macOS / WSL
curl -sSfL https://get.tur.so/install.sh | bash

# или через Homebrew
brew install tursodatabase/tap/turso
```

> ⚠️ На **Windows без WSL** CLI не ставится — используй веб-панель.

Затем в Render → сервис → **Environment** добавь
`DATABASE_URL` и `DATABASE_AUTH_TOKEN`, либо запиши их в `.env`.
`store.js` сам определит режим по наличию `DATABASE_URL`.

> ⚠️ На Render **Free** файловая система эфемерная: при локальном файле
> база переживёт работу инстанса, но **обнулится** при спиддауне (15 мин без трафика)
> и при каждом редеплое. Только внешняя база (Turso/Neon) решает это полностью.

## 🚀 Деплой на Render

1. Запушь репозиторий на GitHub/GitLab.
2. В Render: **New → Blueprint** → укажи репозиторий (Render прочитает `render.yaml`).
   Либо **New → Web Service** с теми же настройками:
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Health Check Path: `/healthz`
3. Проверка после деплоя: `https://<твой-домен>.onrender.com/healthz`

Переменные окружения: `DATABASE_URL`, `DATABASE_AUTH_TOKEN` (Turso), `DATA_DIR`,
`CASES_CACHE_DIR`, `REMOTE_CDN`, `NODE_VERSION`. Подробности — в `.env.example`.

## ⚡ Особенности реализации

1. **Точная верстка и стили (1:1)**:
   - Полный стек стилей Next.js / Tailwind с CSS-переменными темы бренда (`--brand-accent: #44C987`).
   - Оригинальные векторные и растровые ассеты, фирменные шрифты (`Oswald`, `Sofia Sans`, `Noto Sans`, `Rubik`, `Exo 2`, `DS-Digital`).
2. **Интерактивные разделы**:
   - **Апгрейды (`/ru`)**: центральный верстак с барабаном, выбор желаемых скинов, расчет шансов, live drop лента слева.
   - **Кейсы (`/ru/cases`)**: 151 кейс CS2 по категориям (Ножевые, Перчатки, Армейские и др.).
   - **Награды (`/ru/rewards`)**: розыгрыши «Каждый час», «Каждый день», «Каждую неделю» с таймерами и «Еженедельный набор».
   - **Инвентарь (`/ru/inventory`)**: фильтрация, сортировка по новизне и стоимости.
   - **Юридические страницы**: TOS, Политика конфиденциальности, Cookie, AML, Контакты.
3. **Реальный WebSocket сервер (`/api/ws`)**:
   - Динамический онлайн (флуктуация вокруг реальных ~3850–3890 игроков).
   - Живая лента дропов скинов CS2 в реальном времени.
4. **Встроенный Fallback Proxy**:
   - При любых непредвиденных динамических запросах сервер автоматически кэширует оригинальные файлы с CDN источника.
