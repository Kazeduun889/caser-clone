# Caser.one — Полная копия проекта (1:1 Клон)

Точная копия сайта игрового проекта **caser.one** (CS2 кейсы, апгрейд предметов, еженедельные награды и розыгрыши), выгруженная и развернутая с помощью автоматизированного инструмента парсинга и сборщика ассетов.

---

```
caser-site/

│       └── media/             # Шрифты (.woff2)
├── cdn/                       # Все медиа-ресурсы и графические ассеты
│   ├── cases/                 # Арты и обложки всех 151 кейсов
```

## 🚀 Запуск проекта

### 1. Установка зависимостей
```bash
cd caser-site
npm install
```

### 2. Запуск сервера
```bash
node server.js
```
Сервер будет доступен по адресу: **`http://localhost:3000`** (или `http://0.0.0.0:3000`).

## 💾 Хранение данных

Баланс, инвентарь, история транзакций и лог открытий хранятся в **SQLite**
(`store.js`, файл `data/caser.db`, путь настраивается через `DATA_DIR` / `DATABASE_PATH`).

- **Аккаунт выдаётся на первый запрос** и привязывается к cookie `caser_user_id`,
  поэтому у каждого браузера **свой** баланс и **свой** инвентарь.
- Если `better-sqlite3` не удалось загрузить — сервер автоматически падает обратно
  в режим «в памяти» и продолжает работать.
- Ледгер: каждое движение баланса пишется в `transactions`
  (`GET /api/users/balance/history`).

> ⚠️ На Render **Free** файловая система эфемерная: база переживёт работу инстанса,
> но **обнулится** при спиддауне (15 мин без трафика) и при каждом редеплое.
> Для постоянного хранения нужен платный план + persistent disk на `/var/data`.

## 🚀 Деплой на Render

1. Запушь репозиторий на GitHub/GitLab.
2. В Render: **New → Blueprint** → укажи репозиторий (Render прочитает `render.yaml`).
   Либо **New → Web Service** с теми же настройками:
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Health Check Path: `/healthz`
3. Проверка после деплоя: `https://<твой-домен>.onrender.com/healthz`

Переменные окружения (уже заданы в `render.yaml`):
`PORT` (Render подставляет сам), `DATA_DIR`, `CASES_CACHE_DIR`, `REMOTE_CDN`, `NODE_VERSION`.

## ⚡ Особенности реализации

1. **Точная верстка и стили (1:1)**:
   - Полный стек стилей Next.js / Tailwind с CSS-переменными темы бренда (`--brand-accent: #44C987`).
   - Оригинальные векторные и растровые ассеты, фирменные шрифты (`Oswald`, `Sofia Sans`, `Noto Sans`, `Rubik`, `Exo 2`, `DS-Digital`).
2. **Интерактивные разделы**:
   - **Апгрейды (`/ru`)**: центральный верстак с барабаном, выбор желаемых скинов, расчет шансов, live drop лента слева.
   - **Кейсы (`/ru/cases`)**: 151 кейс CS2 по категориям (Ножевые, Перчатки, Армейские и др.).
   - **Награды (`/ru/rewards`)**: розыгрыши «Каждый час», «Каждый день», «Каждую неделю» с таймерами и «Еженедельный набор».
   - **Инвентарь (`/ru/inventory`)**: фильтрация, сортировка по новизне и стоимости.
   - **Юридические страницы**: TOS, Политика конфиденциальности, Cookie, AML, Контакты.
3. **Реальный WebSocket сервер (`/api/ws`)**:
   - Динамический онлайн (флуктуация вокруг реальных ~3850–3890 игроков).
   - Живая лента дропов скинов CS2 в реальном времени.
4. **Встроенный Fallback Proxy**:
   - При любых непредвиденных динамических запросах сервер автоматически кэширует оригинальные файлы с CDN источника.
